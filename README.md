# Healthy Habits

A fitness coaching web app that generates personalized weekly meal plans and workout routines based on a user's goal — bulk, cut, or maintain. The AI coach is powered by the Anthropic Claude API and responds conversationally to nutrition and training questions.

Live site: (https://dnguy634.github.io/Healthy-Habits)

## Stack

Vanilla HTML, CSS, and JavaScript. No build tools, no framework, no dependencies. The only external requests are Google Fonts and the Anthropic API.

## Project structure

```
healthy-habits/
├── index.html      # markup and content
├── styles.css      # layout, theming, animations
├── script.js       # chat logic, API calls, UI interactions
└── README.md
```
